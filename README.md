# Симулятор робота с лидаром

Полнофункциональный симулятор робота с лидарным картографированием, локализацией и навигацией.

## Возможности

- **Редактор карты**: Создание карты с препятствиями (стиль КуМир Стандарт)
- **Слепой робот**: Режим исследования карты с туманом войны (Scanner Sombre style)
- **Лидарное картографирование**: Построение карты занятости (Occupancy Grid)
- **Локализация**: Определение позиции робота на известной карте
- **Планирование пути**: Алгоритм A* для поиска оптимального маршрута

## Запуск

### Windows
```bash
run_map.bat
```

### Linux/Mac
```bash
python main.py
```

### С параметрами
```bash
# Запуск в режиме слепого робота
python main.py --mode blind

# Запуск с конфигом
python main.py --config configs/demo_maze.json

# Запуск с загруженной картой
python main.py --map maps/saved_map.pkl
```

## Использование

### Редактор карты
1. Нажмите кнопку "Редактор карты"
2. Наведите мышь на границу клетки (появится желтая область)
3. ЛКМ - разместить стенку
4. C - очистить все препятствия
5. "Сохранить карту" - сохранить карту в файл

### Слепой робот
1. Нажмите кнопку "Слепой робот"
2. Выберите начальную позицию робота (ЛКМ)
3. Управление:
   - W/↑ - движение вперед
   - S/↓ - движение назад
   - A/← - поворот влево
   - D/→ - поворот вправо
4. Лидар постепенно открывает область вокруг робота
5. C - очистить историю сканов
